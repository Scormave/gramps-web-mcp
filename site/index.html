Model Context Protocol

Give AI agents access to your family tree

Companion MCP server for Gramps Web. Structured, tool-based access to people, families, events, places, sources, and more — through the Model Context Protocol.

Not a standalone genealogy UI. Runs alongside your existing Gramps Web instance.

View on GitHub Docker quickstart Claude Desktop bundle

Features

Built for agents that research trees

Fifty-seven tools, six resources, guided prompts — spanning the full Gramps object model.

57 MCP tools

Read, create, update, and delete people, families, events, places, sources, citations, notes, media, repositories, and tags.

Search & browse

Full-text search and paginated object listing across the tree.

Kinship tools

Ancestors, descendants, relationships, and person timelines.

Composite workflows

Quick-add person, add event to person, find by Gramps ID — multi-step ops in one call.

6 MCP resources

Type vocabularies, input guide, tree metadata, name settings, and opt-in media for vision agents.

Media safeguards

Size limits, MIME allowlists, and private-record defaults. Media bytes off by default.

MCP prompts

Guided workflows for research, adding people and families, and imports.

Multiple transports

stdio for local clients, Streamable HTTP, and legacy SSE for older agents.

Read-only mode

Keep all tools visible while blocking create, update, and delete. Ideal for first sessions.

Quickstart

Up and running in minutes

Docker, Claude Desktop one-click, or wire it into any MCP client.

docker run 
docker pull ghcr.io/scormave/gramps-web-mcp:latest

docker run -p 8080:8080 \
  -e GRAMPS_API_URL=https://your-gramps.example.com \
  -e GRAMPS_USERNAME=your-user \
  -e GRAMPS_PASSWORD=your-password \
  -e GRAMPS_TREE_ID=your-tree-uuid \
  ghcr.io/scormave/gramps-web-mcp:latest

Multi-arch images (amd64, arm64). Health check at GET /health. MCP endpoint at /mcp.

  1. Download the .mcpb for your OS from GitHub Releases.
  2. Double-click it, or drag it into the Claude Desktop window.
  3. Enter your Gramps Web URL, credentials, and tree UUID.
  4. Leave Read-only mode enabled for your first session.
  5. Start a new chat and ask about your tree.
PlatformArtifact

stdio config 
{
  "mcpServers": {
    "gramps-web": {
      "command": "dotnet",
      "args": ["run", "--project", "/path/to/GrampsWeb.Mcp/GrampsWeb.Mcp.csproj"],
      "env": {
        "MCP_TRANSPORT": "stdio",
        "GRAMPS_API_URL": "https://your-gramps.example.com",
        "GRAMPS_USERNAME": "your-user",
        "GRAMPS_PASSWORD": "your-password",
        "GRAMPS_TREE_ID": "your-tree-uuid"
      }
    }
  }
}

For HTTP transport, point your client at http://host:8080/mcp. Add "GRAMPS_READ_ONLY": "true" for a safer first session.

Configuration

Essentials

Four required variables to connect. The rest is optional hardening.

Variable Description
GRAMPS_API_URLBase URL of your Gramps Web instance
GRAMPS_USERNAMEAPI user name
GRAMPS_PASSWORDAPI password or token
GRAMPS_TREE_IDTree UUID on that server
GRAMPS_READ_ONLYBlock mutations while keeping tools visible
